Hot-reload for MCP servers: the agent connects the server it is building, calls a tool, fixes the code, runs `reload()` and calls it again in the same session, with no client restart. Also mounts any of 130,000+ servers from 7 registries mid-session (one tool at a time if you like) and runs community npm/PyPI packages in a hardened Docker container.
