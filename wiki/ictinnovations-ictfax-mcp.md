MCP server for ICTFax, an open source FreeSWITCH-based fax server. Lists inbound and outbound fax transmissions with status, contact and page count, and polls a single transmission after sending. Uploading a document and sending a fax dial a real number and cost money, so neither tool is registered with the model unless `ICTFAX_MCP_ALLOW_WRITE=true`. Talks to the ICTCore REST API. Zero-install via `npx -y ictfax-mcp`.
