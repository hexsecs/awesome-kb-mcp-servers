Bags on Solana: token analytics, creator-fee data and trade quotes, plus gated swaps and fee claims. A write's first call signs nothing: it returns a preview and a single-use confirmation token bound to the exact arguments. Every transaction is then simulated and refused if it would take more SOL than was approved (default cap 0.1 SOL per trade). 100% test coverage enforced in CI, published with npm provenance. `npx -y bagos-mcp-server`
