Build and edit real websites from the coding agent you already pay for — no per-token AI fees. Browse the template catalogue, create and open a site, rewrite sections, add and link pages, insert blocks, keep reusable symbols in sync, screenshot any viewport, and export static HTML/CSS/JS. Drives an open Swebsy Studio tab over a local `127.0.0.1` WebSocket relay; nothing is proxied through our servers and Studio redacts secrets before anything crosses the bridge. Install via NPM: `npx -y @swebsy/mcp setup`
