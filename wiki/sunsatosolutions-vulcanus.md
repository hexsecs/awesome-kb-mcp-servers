Generates a Git-versioned Markdown vault as project memory, then serves it over MCP. `recall` returns a project's capsule plus the read-next list and warns when the capsule is older than the decisions beneath it; `search` ranks by layer; writes are scoped — `update_capsule` replaces one named section rather than rewriting the file. A `doctor` tool validates that every link resolves and every project is reachable, so the memory fails loudly instead of rotting. Plain Markdown, Obsidian-compatible, no database. `npx @sunsato/vulcanus`
