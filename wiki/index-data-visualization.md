# Data Visualization

- [ganapativs/microcharts](ganapativs-microcharts.md) — Word-sized charts (sparklines, bars, bullets and more) rendered to self-contained SVG with generated alt text, plus chart suggestions for a given question.
- [kleinicke/ply-visualizer](kleinicke-ply-visualizer.md) — Inspect, compare and export point clouds, meshes and depth data with interactive 3D previews, measurements, NumPy/PyTorch inputs and COLMAP depth.
- [KyuRish/mcp-dashboards](kyurish-mcp-dashboards.md) — Interactive charts (bar, line, candlestick, Sankey, geo and more) and dashboards with KPI cards, drill-down, live API polling, themes and PNG/PPT export.
- [marzukia/charted](marzukia-charted.md) — Render bar, line, pie, scatter and other charts from JSON or CSV to SVG, HTML, PNG or data URL, with built-in themes.
- [MS-Teja/Glyphic](ms-teja-glyphic.md) — Generate architecture, ERD, sequence, flowchart, Gantt and other diagrams from structured JSON as SVG or PNG, without a headless browser.
- [nuncaeslupus/drawspec](nuncaeslupus-drawspec.md) — Declarative JSON diagram spec rendered to themeable SVG. The format has no coordinates, so an LLM can write a correct diagram; `validate`, `render` and…
- [oscarleoo/chartlink-agents](oscarleoo-chartlink-agents.md) — Charts, maps and sortable tables with live-updating embed links: draft, preview and publish, then update the data and every embed follows.
- [pushtodisplay/cli](pushtodisplay-cli.md) — Send structured content to boards in the Push To Display app on iOS and Android, route updates to specific panels and render them in real time.
- [Ratnaditya-J/csvglow](ratnaditya-j-csvglow.md) — Generate self-contained HTML dashboards from CSV/Excel files with interactive ECharts visualizations and sortable data tables.
- [nteract/semiotic](nteract-semiotic.md) — Semiotic React data visualization: suggest charts for a dataset, render validated configs to SVG, diagnose anti-patterns and fetch component schemas.
